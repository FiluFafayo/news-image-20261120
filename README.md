# Sum up 20 November's world news in one image

Entry for the make.fun bounty `news-image-20261120` ($250, 50 places).

The program copies the front-page image beside it to `/output/entry.png`
(see `main.ts`). The image is a one-page newspaper front page for
Friday, 20 November 2026: Russian strikes on Kyiv's bridges (lead),
the Trump–Xi–Putin Shenzhen summit, the ICJ's Myanmar/Rohingya
genocide ruling, the Hormuz tanker attacks, the COP31 deadlock,
and the record $190.4M Van Gogh sale.

Run locally: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`
